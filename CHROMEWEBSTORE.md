# Chrome distribution

Chrome Web Store publication is on hold at the user’s request. Users load the bundled extension unpacked; no store account or registration fee is required.

The extension ZIP preserves manifest.key so its ID matches the toolkit’s strict origin check. Keep the runtime folder in place and reload after updates. Do not remove or regenerate that key.

If store publication is resumed later, prepare its assigned identity, public privacy/support URLs, publisher details and listing assets before submission. No store approval or automatic Web Store updates are claimed.
